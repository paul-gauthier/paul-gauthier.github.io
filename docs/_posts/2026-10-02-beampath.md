I made a little python DSL for quickly drawing optical setup
diagrams. Something to bridge the gap between a hand drawn whiteboard
sketch and an actual optical table layout. For sharing setups with
colleagues. Or for riffing with LLMs, which can understand and modify
the code easily.

[https://github.com/paul-gauthier/beampath](https://github.com/paul-gauthier/beampath)
